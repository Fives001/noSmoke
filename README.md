# noSmoke

## 금연 앱 (모바일 웹 · PWA)

휴대폰에서 앱처럼 실행되는 금연 기록 앱입니다. 라이브러리 의존성이 없는 단일 HTML이며,
홈 화면에 추가하면 오프라인에서도 실행됩니다.

| 파일 | 설명 |
| --- | --- |
| `index.html` | 금연 앱 본체 (단일 HTML, 외부 라이브러리 없음) |
| `app.webmanifest` | PWA 매니페스트 (홈 화면 추가 · 전체화면 실행) |
| `sw.js` | 서비스 워커 (오프라인 캐시) |
| `icons/` | 앱 아이콘 (192·512·maskable·apple-touch) |

### 기능

- **경과 시간**: 금연 시작 이후 일 수와 시:분:초를 실시간 표시, 최고 기록 보관
- **절약 통계**: 절약 금액 · 안 피운 담배 개비 수 · 되찾은 수명(개비당 11분) · 참은 충동 횟수
- **절약 목표**: 목표 이름·금액을 정하면 달성률과 남은 기간을 계산
- **신분(계급) 시스템**: 금연 기간에 따라 노비 → 임금까지 20계급. 홈 화면에 현재 계급장·다음 승급까지
  남은 시간을 표시하고, 「계급」 탭에서 계급별 조건과 설명을 확인합니다. 승급 시 알림/진동으로 알려줍니다.
  - 천민(노비·면천) → 평민(상민·양인·부농) → 중인(서리·향리·역관·의원) → 양반(유생·생원·진사·현감)
    → 관료(군수·부사·목사·관찰사·판서·정승) → 왕가(임금)
  - 승급 시점: 1일·3일·1주·2주 → 4·6·8·10주 → 12·16·20주 → 6개월·9개월·1년 → 1.5년·2년·3년·5년·10년
  - 계급장은 외부 이미지 없이 SVG로 그립니다(패랭이·초립·탕건·갓·사모·면류관 + 그룹 내 서열 점)
- **건강 회복 타임라인**: 20분 ~ 15년까지 15단계, 달성 여부와 다음 단계까지 남은 시간 표시
- **충동 대응**: 「참았어요」 기록, 4분 호흡 가이드(4-2-6-2 리듬), 「한 대 피웠어요」 기록 후 재시작 선택
- **기록**: 최근 7일 막대 그래프(참음/흡연), 상황 메모, 기록 개별 삭제
- **배지**: 첫 24시간 · 3일 고비 · 1주 · 2주 · 한 달 · 100일 · 반 년 · 1년
- **알림**: 새 건강 단계 달성 시 브라우저 알림(선택)
- **데이터**: 기기 내 localStorage 저장, JSON 내보내기/가져오기, 전체 초기화

### 모바일 대응

- 세로 화면 기준 반응형(320px 폭까지 가로 스크롤 없음), 하단 탭 5개(홈·계급·건강·기록·설정)
- 노치·홈 인디케이터 대응(`viewport-fit=cover` + `safe-area-inset`)
- 터치 영역 최소 44px, 입력 글자 16px(iOS 자동 확대 방지), 탭 시 진동 피드백
- 라이트/다크 모드 자동 전환, 상태바 색상(`theme-color`) 대응

### 실행 방법

로컬 파일로 열어도 동작하지만, 홈 화면 추가·오프라인 캐시는 `http(s)`에서만 동작합니다.

```bash
npx http-server -p 8099 .      # http://<PC의 IP>:8099/index.html
```

- **Android(Chrome)**: 주소 열기 → 상단 안내 배너 또는 메뉴 → **앱 설치 / 홈 화면에 추가**
- **iOS(Safari)**: 주소 열기 → 공유 → **홈 화면에 추가**

기록은 브라우저에만 저장되므로 기기를 바꾸기 전에 **설정 → 데이터 → 내보내기**로 백업하세요.

> 타임라인의 건강 정보는 일반적인 의학 정보이며 개인차가 있습니다. 치료가 필요한 경우 전문가와 상담하세요.

## 통합검색 5자리 우편번호 조회 화면

우정사업본부 「통합검색 도로명주소 및 지번주소 5자리 우편번호 조회 서비스」
(`getNewAddressListAreaCdSearchAll`) 사양서를 기준으로 만든 웹 검색 화면입니다.

| 파일 | 설명 |
| --- | --- |
| `address-search.html` | 주소 검색 화면 (라이브러리 의존성 없는 단일 HTML 파일) |
| `proxy-server.js` | 개발용 CORS 프록시 (Node 기본 모듈만 사용) |

### 화면 기능

- 검색어(`srchwrd`) · 페이지당 개수(`countPerPage`, 최대 50) 입력
- 결과 목록: 우편번호(5자리) / 도로명주소(`lnmAdres`) / 지번주소(`rnAdres`)
- 검색어 하이라이트, 페이지 이동(`currentPage`), 전체 건수·페이지 표시
- 행 「선택」 시 상세 표시 + 클립보드 복사
- 인증키·프록시 주소는 브라우저 localStorage에 저장
- 데모 모드: 인증키 없이 내장 샘플 데이터로 화면 동작 확인

### 사용 방법

**1) 데모 모드** — `address-search.html`을 브라우저로 열고 바로 검색합니다.

**2) 실제 API 조회** — 오픈API 서버(`openapi.epost.go.kr`)는 CORS 헤더를 내려주지 않아
브라우저에서 직접 호출할 수 없습니다. 함께 포함된 프록시를 사용하세요.

```bash
node proxy-server.js                    # http://localhost:8080/postal
SERVICE_KEY=발급받은키 node proxy-server.js  # 인증키를 서버에 두는 방식(권장)
```

화면의 **API 연결 설정**에서

- 프록시 URL: `http://localhost:8080/postal`
- 서비스 인증키: 공공데이터포털에서 발급받은 키 (프록시에 `SERVICE_KEY`를 지정했다면 생략 가능)
- 데모 모드: 체크 해제

### 응답 형식 관련 참고

사양서 본문의 예시 응답은 `<xsync>/<xsyncData>` 구조지만, 실제 운영 서버는
응답 메시지 명세 표와 동일한 구조로 내려줍니다.

```xml
<NewAddressListResponse>
  <cmmMsgHeader>
    <successYN>Y</successYN><returnCode>00</returnCode><errMsg/>
    <totalCount>23</totalCount><countPerPage>10</countPerPage>
    <totalPage>3</totalPage><currentPage>1</currentPage>
  </cmmMsgHeader>
  <newAddressListAreaCdSearchAll>
    <zipNo>12621</zipNo>
    <lnmAdres>경기도 여주시 세종로 17 (홍문동)</lnmAdres>
    <rnAdres>경기도 여주시 홍문동 111-15</rnAdres>
  </newAddressListAreaCdSearchAll>
  ...
</NewAddressListResponse>
```

화면은 **두 형식을 모두 파싱**하며, `errMsg` 또는 `successYN=N` 인 경우 오류 메시지를 표시합니다.
